## 🎯 프로젝트 목적

**일공로그**는 단순한 가계부를 넘어, **소비를 돌아보고 기록하는 습관**을 만드는 개인 금융 앱입니다.

투자에는 관심이 많지만 일상 소비에는 무심한 20대를 위해 만들어졌습니다. 단순히 "얼마를 썼는지" 기록하는 데 그치지 않고, **"왜 그렇게 썼는지", "그 소비에 얼마나 만족했는지"** 를 돌아보게 하는 것이 핵심입니다.

- **가계부 기능으로 소비 흐름을 한눈에** — 수입·지출을 기록하고 달력과 통계로 흐름을 파악합니다.
- **회고로 소비를 돌아보는 습관** — 하루 1분, 오늘의 소비에 대한 만족도와 한 줄 평을 남깁니다.
- **과하지 않은, 차분한 톤** — 게임 요소나 귀여운 캐릭터 없이, 저널링 앱처럼 차분하고 성숙한 분위기를 지향합니다.

## ✨ 주요 기능

### 📅 캘린더
- 일별 수입·지출 금액을 색상으로 구분해 표시 (수입은 파란색, 지출은 빨간색)
- 회고를 남긴 날은 검정 점으로 표시
- 날짜를 선택해 수입·지출 내역을 손쉽게 추가 (카테고리, 금액, 메모, 고정 수입/지출 여부)

### 📊 통계
- 이번 달 소비 흐름을 한 줄 평으로 요약
- 지난달과의 수입·지출·카테고리별 비교
- 카테고리별 지출/수입 비중을 도넛 차트·막대 차트로 시각화
- 카테고리를 선택하면 관련 소비 내역을 함께 확인

### 📝 회고
- **오늘의 소비 만족도** 별점 입력
- 오늘 기록한 소비 중 **가장 만족스러운 소비 / 후회되는 소비** 선택
- 오늘 소비에 대한 **한 줄 평** 작성
- *(예정) AI 기반 월간 회고 리포트*

### ⚙️ 더보기
- Google 계정 프로필 표시
- 수입·지출 카테고리 추가/수정/삭제 관리
- 알림 설정, 계정 관리, 개인정보처리방침

## 🛠 기술 스택

### Frontend
- **React 19** + **TypeScript**
- **Vite** (빌드 도구)
- **Tailwind CSS 4** (스타일링)
- **Zustand** (전역 상태 관리)
- **React Router DOM 7** (라우팅)
- **Heroicons** (아이콘)

### Backend
- **Supabase** (Tokyo 리전)
  - 인증 (Google OAuth)
  - PostgreSQL Database
  - Edge Functions

### Deployment
- **Vercel** (GitHub 연동 자동 배포)

## 🗂 데이터베이스 구조

| 테이블 | 설명 |
| --- | --- |
| `categories` | 수입·지출 카테고리 |
| `transactions` | 거래 내역 (소비 만족도 `satisfaction` 포함) |
| `journal_entries` | 일일 회고 기록 (한 줄 평, 만족/후회 소비) |
| `monthly_goals` | 월별 예산 목표 |

## 🚀 시작하기

### 요구 사항
- Node.js 20 이상

### 설치 및 실행

```bash
# 저장소 클론
git clone <repository-url>
cd ten-log

# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

### 환경 변수

프로젝트 루트에 `.env` 파일을 생성하고 Supabase 연결 정보를 입력합니다.

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 스크립트

| 명령어 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | 프로덕션 빌드 |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run lint` | ESLint 검사 |
